# Spotitube Downloader

Aplicação desktop desenvolvida em Python para fins acadêmicos e educacionais.

## Objetivo

Demonstrar conceitos de:

- Interface gráfica com PySide6
- Multithreading
- Processamento de áudio
- Integração com ferramentas externas
- Persistência de configurações
- Automação de tarefas

## Funcionalidades

- Download de playlists do Spotify
- Download de músicas do Spotify
- Download de playlists do YouTube
- Download de vídeos do YouTube em MP3
- Normalização automática de áudio
- Seleção de pasta de destino
- Interface gráfica desktop

## Tecnologias

- Python
- PySide6
- FFmpeg
- SpotDL
- yt-dlp
